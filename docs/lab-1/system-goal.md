# Цель системы

Система помогает студенту подготовиться к зачёту по собственному конспекту: выделить ключевые факты, проверить карточки по источнику и повторить материал без подсказки.

**Признак достижения цели в пилоте:** через 14 дней после начала не менее 60% всех участников, начавших пилот, набирают минимум 7 баллов из 10 на закрытой проверке по своему материалу.

**Как измеряем:** до начала пилота для каждого участника фиксируем 10 ключевых фактов. На 14-й день он отвечает без конспекта. Каждый факт получает 1 балл, если смысл ответа верен по заранее согласованной рубрике, и 0 в противном случае. Доля успеха = число участников с результатом не ниже 7/10 / число всех начавших пилот. Пропуск проверки считается недостижением цели.

Порог 60% — рабочая цель, а не полученный результат и не обещание сдать зачёт. Чтобы проверить, является ли он амбициозным, до пилота нужно сравнить результат на 14-й день с сопоставимой группой, которая готовилась тот же период без сервиса, по тому же протоколу и рубрике. Если не использовавшая сервис группа уже достигает 60% на уровне 7/10, порог или целевой прирост нужно пересмотреть совместно с Quality & Safety. Мнение студентов о полезном для них результате можно собрать отдельно, но оно не заменяет измерение знаний. При небольшой выборке сравнение будет предварительным, без обобщения на всех студентов; если сопоставимую группу набрать нельзя, 60% остаётся непроверенной рабочей целью, а не доказанно высокой планкой.
