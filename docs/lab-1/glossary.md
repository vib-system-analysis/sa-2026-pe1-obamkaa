# Глоссарий команды

Рабочие определения для проекта карточек повторения. Термины нужно согласовать вслух со всей командой и обновлять по мере появления новых решений.

| Термин | Определение в контексте проекта |
| --- | --- |
| Конспект | Материал лекции, который студент загрузил для подготовки карточек. В пилоте это текст или PDF. |
| Исходный фрагмент | Конкретный отрывок конспекта, на котором основаны вопрос и ответ карточки. |
| Карточка | Одна единица самопроверки: вопрос, ожидаемые ключевые факты и ссылка на исходный фрагмент. |
| Вопрос | Формулировка, побуждающая вспомнить конкретное понятие или связь без показа ответа. |
| Эталонный ответ | Краткий набор ожидаемых фактов, а не единственная допустимая формулировка ответа студента. |
| Ключевой факт | Отдельное проверяемое утверждение, которое необходимо вспомнить для правильного ответа. |
| Колода | Набор карточек, созданных из одного конспекта или выбранной темы. |
| Генерация | Преобразование конспекта в черновые карточки с помощью выбранного подхода или модели. |
| Проверка источником | Сверка каждого ключевого факта карточки с указанным исходным фрагментом. |
| Ошибка источника | Утверждение в карточке, которое отсутствует в конспекте, противоречит ему или искажает его смысл. |
| Дубликат | Карточка, которая проверяет то же знание, что уже проверяет другая карточка набора. |
| Ответ своими словами | Ответ студента, в котором смысл и ключевые факты верны, но формулировка отличается от эталонной. |
| Самопроверка | Сессия, в которой студент сначала отвечает без подсказки, затем сравнивает ответ с критериями. |
| Сессия повторения | Один проход по карточкам, в ходе которого фиксируются ответы и результат самопроверки. |
| Интервал повторения | Время между сессиями для одной карточки или колоды. В пилоте задаётся простым расписанием. |
| Возврат к повторению | Факт начала следующей сессии после первой; в пилоте измеряется по времени между сессиями. |
| Пилот | Ограниченная проверка сценария с целевой группой, заранее заданными условиями и способом измерения результата. |
| Целевой сегмент | Группа людей в конкретной ситуации, чью проблему продукт проверяет в первую очередь. |
| Респондент | Участник проблемного интервью, рассказывающий о собственном прошлом опыте. |
| Рецензент | Участник проверки карточек, который оценивает их полезность и соответствие источнику по заданным критериям. |
| North Star | Основной показатель ценности продукта для целевого студента, определённый заранее и имеющий способ подсчёта. |
| Фальсифицируемая гипотеза | Предположение с заранее указанным наблюдением или порогом, который покажет, что предположение неверно. |
| Порог достижения | Заранее установленное числовое условие, по которому решают, достигнут ли ожидаемый результат. |
| Golden dataset | Версионируемый набор примеров входа и согласованных эталонных карточек для повторяемой оценки качества. |
| Латентность | Время от отправки запроса на обработку конспекта до готового набора карточек. |
| p95 | 95-й процентиль времени обработки: 95% запросов завершаются за это время или быстрее. |
| Токен-бюджет | Допустимые затраты токенов или денег на один заранее определённый сценарий обработки. |
