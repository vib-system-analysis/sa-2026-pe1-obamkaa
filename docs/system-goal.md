# Цель системы

Система помогает студенту подготовиться к зачёту по собственному конспекту: выделить ключевые факты, проверить карточки по источнику и повторить материал без подсказки.

**Признак достижения цели в пилоте:** через 14 дней после начала не менее 60% всех участников, начавших пилот, набирают минимум 7 баллов из 10 на закрытой проверке по своему материалу.

**Как измеряем:** до начала пилота для каждого участника фиксируем 10 ключевых фактов. На 14-й день он отвечает без конспекта. Каждый факт получает 1 балл, если смысл ответа верен по заранее согласованной рубрике, и 0 в противном случае. Доля успеха = число участников с результатом не ниже 7/10 / число всех начавших пилот. Пропуск проверки считается недостижением цели.

Порог 60% — рабочая цель, которую нужно согласовать с Quality & Safety до пилота; это не полученный результат и не обещание сдать зачёт.
