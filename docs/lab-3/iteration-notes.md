# Итерационные заметки: лабораторная 3

**Дата:** 2026-10-27  
**Основание:** проверка состава ветки `lab3-product-prototype`; живого прототипа в ней нет.

## Что изменилось после встречи с прототипом

Пока ничего: прототип не запущен, поэтому утверждать, что сценарий прошёл или требования подтверждены, нельзя. Требования PRD и UC оставлены без тихих правок. В [матрице валидации](use-cases/prototype-validation.md) записаны заблокированные сквозные пути и доказательства, которые нужно собрать.

## План следующей итерации

| Работа | Владелец | Результат / критерий приёмки |
| --- | --- | --- |
| Собрать вертикальный прототип загрузки, колоды и повторения | Delivery | Один запускаемый контур UI → API → модель → БД; доступен тестовый URL или воспроизводимый compose |
| Подключить baseline-генерацию и сохранение источника | AI Engineer | Черновик содержит структурированные вопрос, факты и фрагмент источника; ошибки API обрабатываются |
| Подготовить минимальный golden dataset и прогнать evals | Quality & Safety + AI Engineer | Набор версионирован; метрики и живые примеры ошибок приложены к отчёту |
| Пройти UC-01–03 и E2E с человеком вне команды | Product / VO | Записаны фактические шаги, неожиданности, разрывы, решения и повторные проверки |
| Обновить требования по результатам | Product / VO | PRD/UC меняются явными правками с ссылкой на наблюдение или eval |

## Техдолг и решения

Техдолг по результатам прототипа пока не принимается: его цена не измерена, потому что прототип отсутствует. Решение о локальном хранении, доступе к конспектам и fallback-модели остаётся в соответствующих ADR/планах и должно быть согласовано до пилота.
